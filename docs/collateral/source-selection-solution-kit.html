2Stage a new evaluation

The live demo starts three weeks into an evaluation: intake done and two of the three evaluators submitted, so the audience watches Tom finish his worksheet and the evaluation run on to award. Staging takes about ten minutes with the federal VA package below.

  1. As Dana Whitfield, open New source selection and upload Solicitation.pdf, IGCE.pdf and Section-M.pdf. The agents fill in the plan; check it against the expected values below.
  2. Assign the evaluation board (who rates which factor), add all 15 proposal volumes (they match to each offeror by file name), check the plan and start the source selection. Robots ingest and screen the proposals in a minute or two.
  3. Still as Dana, open the release task in My tasks and release the proposals to the evaluators. The evaluation agent drafts findings for each worksheet.
  4. As Marcus Reyes, open his worksheet, accept, edit or reject each drafted finding, rate his factors, confirm the independence statement and submit. Then do the same as Priya Natarajan.
  5. Stop there. Tom Okafor's worksheet, the consensus (Rebecca), price (Dana) and award decision (James) are the live demo.

4Reset and rerun

Start over with the same number

Sign in as Jordan Ellis (System Admin) and choose Delete evaluation. It cancels the run, then deletes the proposal files and every record. Stage it again from section 2.

Clear the work between takes

Keep the evaluation but clear its offerors, pages, findings, ratings, decisions and audit events, and set it back to Proposals Received:

python3 tools/reset.py <solicitation>

The terminal version of Delete evaluation is python3 tools/delete_solicitation.py <solicitation> --confirm <solicitation>. Both are permanent.

5Stand it up in another tenant

Only needed outside uipathlabs. The apps, robots and process find folders by key, so point them at your own folder and bucket keys before you deploy.

  1. Clone the repo and sign in: uip login.
  2. Create a folder with the SS-Proposals and SS-Records storage buckets (keys go in tools/schema/bucket-keys.json).
  3. Create the Data Fabric entities from tools/schema/*.json and record their IDs in tools/schema/entity-ids.json, then load the vendor reference data and demo evaluations with python3 tools/seed.py.
  4. Create the three IXP projects (proposal cover, price schedule, past performance), train them on the corpus from tools/generate_ixp_corpus.py and publish each with the live tag.
  5. Pack, publish and deploy the solution (Maestro process, six agents and the robots): 
    cd SourceSelection
uip solution resources refresh
uip solution pack . dist -v <version>
uip solution publish dist/<package>.zip
uip solution deploy run -n SourceSelection --package-name SourceSelection \
  --package-version <version> --folder-name <folder> --parent-folder-path <parent>
  6. Build and deploy the two coded apps, ss-workspace (type Web) and ss-taskforms (type Action): 
    npm run build
uip codedapp pack dist -n <name> -v <version>
uip codedapp publish -n <name> -v <version> -t Web   # -t Action for ss-taskforms
uip codedapp deploy -n <name> --folder-key <folder key>
