## 1. App Overview

The source selection workspace for every persona: portfolio of solicitations, a persona switcher (Evaluator 1–3, SSEB Chair, Contracting Officer, SSA), a persona-filtered task inbox that opens Action Center tasks, the offeror × factor ratings matrix, the protest trace, and Start Source Selection for the Contracting Officer.

### In Scope

Everything listed in §3.

### Out of Scope

Contract writing, discussions/FPR management, debriefings.

### Assumptions

Shared Labs external OAuth app (`uipathlabs` / `Playground`); synthetic data.

## 2. App Type & Tech Stack

### App Type

Coded Web App.

### Tech Stack

Vite, React, TypeScript, `@uipath/uipath-typescript`, `@uipath/apollo-wind` (light/dark), lucide-react.

## 3. Pages & Routes

| Route / form | Page | Purpose |
|---|---|---|
| `/` | Portfolio | Solicitations with stage, offerors, days in stage, open tasks; Start Source Selection |
| `/s/:id` | Solicitation overview | Stage timeline (case history), offerors with compliance/SAM badges, plan factors and relative importance |
| `/s/:id/matrix` | Evaluation matrix | Offeror × factor grid: individual ratings, spread badge, consensus rating, price row |
| `/s/:id/trace/:ratingId` | Protest trace | Rating → consensus rationale → findings → agent draft vs evaluator edit diff → proposal page |
| `/tasks` | My tasks | Persona-filtered Action Center tasks with open link |
| `/plans` | Evaluation plans | Side-by-side plans — the reuse story |

## 4. Components

PersonaSwitcher, StageTimeline, OfferorCard, RatingsMatrix, SpreadBadge, TraceTimeline, PageViewer, DiffView, TaskList, PlanCard, StartCaseDialog.

## 5. State Management

### Global State

Persona in local storage; data via SDK with pagination loops; polling while a case stage is active.

### Local Component State

Form drafts, selected offeror/factor, viewer page.

| Action Center tasks | list for the persona's recipient/labels |
| Buckets SS-Proposals / SS-Records | read URIs for PDFs |

## 7. User Flows

### Flow: Primary

CO picks Start Source Selection → chooses plan FA8771-27-R-0012 → panel defaults to current user → case starts → portfolio shows Proposal Intake → later, switch persona to SSA → open matrix → click Offeror A Technical → protest trace shows the page.
