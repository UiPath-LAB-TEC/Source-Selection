## 1. App Overview

One Coded Action App rendered inside Action Center for all six human tasks in the SourceSelection case. The form is chosen by the `actionType` input: releaseToEvaluation, individualEvaluation, consensus, priceDetermination, awardDecision, clarification.

### In Scope

Everything listed in §3.

### Out of Scope

Contract writing, discussions/FPR management, debriefings.

### Assumptions

Shared Labs external OAuth app (`uipathlabs` / `Playground`); synthetic data.

## 2. App Type & Tech Stack

### App Type

Coded Action App.

### Tech Stack

Vite, React, TypeScript, `@uipath/uipath-typescript`, `@uipath/apollo-wind` (light/dark), lucide-react.

## 3. Pages & Routes

| Route / form | Page | Purpose |
|---|---|---|
| (actionType) releaseToEvaluation | Release form | Compliance table per offeror; Release / Cancel Solicitation |
| individualEvaluation | Evaluation worksheet | Offeror tabs; agent draft findings with Accept/Edit/Reject; add finding; proposal page viewer at the cited page; rating per assigned factor with rationale; independence attestation |
| consensus | Consensus board | Evaluator ratings side by side with spread; agent proposed consensus + questions; set consensus rating + narrative; Sign SSEB Report / Reconvene Evaluators |
| priceDetermination | Price review | Price table vs IGCE, unbalanced lines; determination text; Proceed / Cancel Solicitation |
| awardDecision | Decision room | Ratings matrix + price; agent SSDD draft (editable); awardee picker; signature |
| clarification | Clarification | Chair questions; edit own findings/ratings; notes |

## 4. Components

FindingCard, PageViewer, RatingPicker, OfferorTabs, RatingsMatrix, PriceTable, SsddEditor, SignatureBlock, AttestationCheckbox.

## 5. State Management

### Global State

Task inputs from Action Center; working copy of findings/ratings loaded from Data Fabric by solicitationId and saved on submit; task outputs per the case SDD Output Schema.

### Local Component State

Form drafts, selected offeror/factor, viewer page.

## 6. API Integration

| Call | Purpose |
|---|---|
| Data Fabric `SSFinding`, `SSRating`, `SSProposalPage`, `SSOfferor`, `SSSolicitation`, `SSDecision`, `SSAuditEvent` | read/write |
| Action Center task completion | host-injected session (`new UiPath()`, no initialize) |

### UiPath API Workflow Calls

None.

### Integration Service Connections

None.

## 7. User Flows

### Flow: Primary

Evaluator opens task → sees Offeror A draft findings, each with a cited page → clicks a citation, the page renders beside it → accepts two, edits one, rejects one, adds one → rates Technical Approach Good with rationale → attests → Submit; findings saved with Author = evaluator and Status Edited/Accepted/Added.

## 8. Error Handling

Toast with retry on SDK errors; unsaved-changes guard on forms; empty states.

## 9. Integrated Components

### Called By (if Action app)

SourceSelection case — every `action` task (6), recipients bound from case inputs.

### HITL Form Role

Inputs: actionType, solicitationId and task-specific fields (complianceSummary, consensusDraft, priceAnalysis, ssddDraft, recommendedAwardee, chairQuestions, evaluatorSlot). Outputs: releaseDecision, releaseRationale, evaluator1Ratings/2/3, consensusDecision, consensusRatings, priceDecision, priceDetermination, selectedAwardee, signedSsdd, clarificationNotes. Outcomes: Submit plus decision outcomes per form.
